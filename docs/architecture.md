
# Thermal Twins

## Project
MODIS + VIIRS Hotspot Harmonization

## Objective
Build a sensor-aware platform for comparing satellite
active-fire observations and exploring historical
burning activity.

## Data sources
- NASA FIRMS
- MODIS
- VIIRS

## Processing pipeline
1. Data ingestion
2. Validation
3. Normalization
4. Spatial harmonization
5. Temporal harmonization
6. Cross-sensor association
7. Historical analytics
8. API delivery
9. Visualization

## Backend
- Python
- FastAPI
- Pandas
- NumPy
- SQLite

## Frontend
- Next.js
- TypeScript
- Tailwind CSS
- Leaflet
- Recharts

## Core features
- Interactive hotspot map
- Region and date filters
- MODIS vs VIIRS comparison
- Burning activity calendar
- Historical activity analysis
- CSV export
